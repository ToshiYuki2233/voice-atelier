# 検証結果

確認日：2026-09-13。本番表示への変更後、Windows / Node.js 24.14.0 / Chrome 152.0.7977.83で再検証。

## 実行して通ったもの

- npm.cmd run check：JavaScriptの構文検査。
- npm.cmd test：13件、成功13・失敗0。
- npm.cmd run test:browser：Chromeの仮想マイクを使ったブラウザ検証が成功。

| 対象 | 確認した範囲 |
| --- | --- |

## ブラウザ検証の範囲

- 起動時の未計測表示・「感情解析モデル：未導入」の表示。
- 「本番表示へ」「通常表示へ」の切替、Escでの復帰、手動お題の切替と一巡。
- 仮想マイクの入力でステージの描画が変わり、停止後は待機時の描画に戻ること。
- キャッシュ準備完了。実際のCache Storageに11個の静的資産。
- Chromiumの仮想マイクと実際のWeb Audioグラフで入力レベルの更新。
- 実クリック操作による開始・停止と、追加3回の再試行。停止後のtrack.readyState確認と表示消去。
- document.hiddenをテストで変更してvisibilitychangeを発火した場合の停止と、復帰後の非自動再開。
- NotAllowedErrorをテストで返した場合の許可拒否案内。
- HTTPキャッシュを無効化し、CDPでネットワークをオフラインにした状態で新しい文書を再読み込み。Service Workerから起動し、再び仮想マイクを開始・停止。
- 通常表示・本番表示ともに1180 / 820 / 390 CSS px幅で水平スクロールのはみ出しなし。
- ページの観測リクエストはローカルGETのみ。ページからのWebSocketや未処理JS例外なし。
- Cookie・localStorage・sessionStorage・IndexedDBにアプリデータなし。

上記のネットワーク観測はページのCDPイベントが対象であり、PCやChrome全体の通信監査ではありません。Service Workerは別途コードと動作テストで固定資産だけを扱うことを確認しました。ブラウザテストは仮想マイクだけを利用し、実ユーザーの音声は収集していません。
