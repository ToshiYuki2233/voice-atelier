# データの扱いと計測

## 利用者の声を学習に使わない

利用者の声・台詞・解析結果を、端末内外での追加学習、微調整、個人適応、モデル改善、声の複製に使用しません。個人用の声のプロファイルも蓄積しません。

将来の感情モデルは、公開済みの固定されたモデルでその場の結果を計算する「推論」だけに使用します。「学習済みモデル」は提供元があらかじめ学習したモデルという意味で、このアプリの利用者の声を学習させる方針ではありません。現在は感情モデル未導入です。

クラウドAPIや外部デモへ音声を送る方法は採用しません。比較検証でも同じ条件を守ります。モデル導入時は、コード・同梱ライブラリ・通信・永続領域を確認し、通信を切った状態で動作を検証します。モデル名だけで学習されないと保証せず、実際に組み込む構成を検証します。

## データの経路

マイク → ブラウザのMediaStream → Web AudioのAnalyserNode → 現在の短い音声窓 → RMS・周期性の計算 → 画面。

PCのサーバーへ届くのはアプリ資産のGET/HEADだけです。音声・解析結果を受け取るAPIはありません。アプリにfetch等による音声送信、WebSocket、WebRTC通信、SpeechRecognition、MediaRecorder、外部スクリプト、アクセス解析はありません。通常動作で外部サイトへの自動通信を要求しません。資料の外部リンクは利用者が開いたときに外部ページへ移動します。

ブラウザやOS自体の通信・メモリ管理をアプリが制御することはできません。ここでいう保存しないとはアプリが音声のファイル化や永続領域への書き込みをしない意味です。メモリのフォレンジック上の完全消去を保証する表現ではありません。

## 一時的なメモリ

- AnalyserNodeから取得する現在の窓は4096サンプル。48 kHzでは約85 msです。ブラウザ内部の音声処理バッファも一時利用します。
- 10 Hzで取得・計算・描画します。JavaScriptの音声配列は各描画後にゼロクリアします。読みやすさのため直近1件の実際の高さの検出値と時刻のみをメモリに最大1.5秒保持し、直前の値であることを表示します。未検出のまま保持期限を延長しません。検出値の履歴や音声履歴は蓄積しません。
- 停止・非表示・pagehide・入力中断ではトラックを停止し、ノードを切断し、AudioContextを閉じ、配列をゼロクリアし、画面を初期化します。
- 許可ダイアログ中に停止しても、後から許可されたストリームを直ちに停止する世代番号チェックがあります。
- 音声をスピーカーへ再生しません。処理グラフの末端はゲイン0です。

## 永続領域・配信

Cache StorageにはService Workerの固定リストにあるアプリ資産だけを置きます。マイク音声・結果をLocalStorage、IndexedDB、Cookie、ファイルへ書き込みません。保存されるPNGは固定のアプリアイコンです。サーバーはアクセスログを出さず、起動案内と起動失敗のみ標準出力に表示します。HTTPのPOST等は405で拒否し、任意パス・クエリ・証明書ファイルは公開しません。

CSPは通信先・スクリプト・画像を同一オリジンに限定し、Service Workerは許可資産以外のリクエストを拒否します。これらは多層の制限であり、改変されたコードに対する完全なデータ流出防止機構という意味ではありません。アプリ外のホスティングに移す場合はアクセスログ・解析タグが付加されない設定を別途確認してください。

## 実測値の意味

| 表示 | 計算・限界 |
| --- | --- |
| 入力波形 | 現在の音声窓を固定振幅スケールで描画。待機時は水平線のみ |
| RMS dBFS | 20 log10(sqrt(mean(sample²)))。無音は「—」、−60未満は閾値表示。音圧dB SPLではない |
| 基本周波数Hz | YIN方式を参考にした累積正規化差分と放物線補間。60〜1,000 Hz。RMSが0.003未満、周期が不明瞭なら新たな値を推定しない。直前値の最大1.5秒表示後に「—」 |
| 本番表示の光 | 現在のdBFSを−60〜−6の範囲で光の半径に割り当て、高さ60〜1,000 Hzの対数を縦位置・色相に割り当てる。表示範囲外の音量は端で固定。感情判定ではない |
| 入力上限の案内 | 現在窓の絶対振幅ピークが0.99以上の場合。厳密なクリッピング判定ではない |

基本周波数は計算量を抑えるため平均化して12 kHz以下に間引き、周期性の候補をしきい値0.12で選びます。学習モデルや感情確率ではありません。話者認識・発話検出ではないので、楽器や機械音にも周期を検出し得ます。倍音、騒音、ささやき、声域端では誤推定・欠測が起こります。

マイクへの自動ゲイン・ノイズ抑制・エコー除去の無効化は希望値として要求しますが、端末が従う保証はありません。取得できた実設定を画面下に表示します。不明な設定は不明と表示し、マイク名や端末識別子は表示・保存しません。
