# iPad実機チェックリスト

**現時点で全項目がiPad実機未検証です。** Windowsのブラウザテストや合成信号テストで代替したことにはしません。Safariタブとホーム画面からのPWAの両方で実施してください。結果記録に音声や声の計測値を保存しないでください。

記録欄：確認日 / iPad機種 / iPadOS版 / Safari・PWA / 内蔵・USB・Bluetoothマイク / 合否 / 再現手順。声の内容や生データは不要です。

## 導入・表示

- [ ] 信頼済みHTTPSで警告なしにアクセスできる。証明書のSANがPCのIPと一致する。
- [ ] 起動時にマイク使用表示が出ず、開始ボタンが押せる。
- [ ] 「感情解析モデル：未導入」が見える。感情の点数・演技力・魅力度の数値がない。
- [ ] 入力前の数値が「—」で、偽の波形アニメーションがない。
- [ ] 縦・横・Split Viewで操作や本文がはみ出さず、タップしやすい。
- [ ] VoiceOverでボタン・状態・単位が分かる。高速の数値更新を常時読み上げない。
- [ ] 「本番表示へ」で審査員に見せる画面に切り替わり、「停止」「通常表示へ」が操作できる。
- [ ] 本番表示でも感情モデル未導入が分かる。光の色を感情の判定結果だと誤解しない。
- [ ] 「次のお題」で静かな語りかけ → 弾むような呼びかけ → 力強い宣言と切り替わる。お題を変えただけでは光が変化しない。
- [ ] 審査員との実際の距離・会場の明るさで、光と台詞が見える。iPadを横向きにした場合も確認する。

## マイクと計測

- [ ] 開始タップで許可を求められ、許可後に声へ反応する。スピーカーから入力音を再生しない。
- [ ] 拒否すると案内が出る。設定で許可し直して再開できる。
- [ ] 許可ダイアログを放置・キャンセルしても操作不能にならない。
- [ ] 許可待ち中に停止し、その後許可してもマイクが動き続けない。
- [ ] 小声・通常・大声で入力レベルと波形が変わる（声の評価をしているわけではない）。
- [ ] 母音を伸ばし、声の高さの上下に推定Hzが追従する。値の正確性は必要なら別の信頼できる測定器と確認。
- [ ] 無音・ささやき・摩擦音・騒音で不確かなHzを出し続けない。誤推定があれば限界として記録。
- [ ] 高さを検出できない間、直前の実際の値を最大1.5秒、その旨を明記して表示する。その後は数値が消え、光が中央に戻る。
- [ ] 小声・大声で光が広がり、低い声・高い声で光の上下と色が変わる。周囲の音にも反応し得るため、本番の設置位置で確認する。
- [ ] 画面の解析レート・マイク処理設定が表示される。端末で違うことを確認する。

## 停止・中断

- [ ] 停止後にOSのマイク使用インジケーターが消え、数値と波形が初期化される。
- [ ] 開始／停止を20回繰り返してストリームが増えず、二重処理にならない。
- [ ] タブ切り替え、ホーム画面移動、画面ロック、別アプリ、戻る／進むでマイクが止まる。
- [ ] 復帰後に勝手に再開しない。手動開始で再開できる。
- [ ] 通話・Siri・オーディオ割り込み後に停止案内が出て、再開できる。
- [ ] Bluetooth切断／外付けマイク抜去で停止・中断を検知する。内蔵への自動切替の挙動も記録する。

## オフライン

- [ ] 接続中の初回読み込みで「オフライン準備完了」が出る。
- [ ] 初回取得の途中で切断した場合に、準備完了を誤表示しない。
- [ ] ホーム画面追加後、そのアイコンから接続中に開き、準備完了を確認する。
- [ ] アプリを完全終了 → 機内モードかつWi-Fiオフ → ホーム画面起動が成功する。
- [ ] 上記状態で新たにマイクを開始し、表示・停止が使える。
- [ ] iPad再起動後、PC停止中でも起動・マイク操作できる。
- [ ] 容量不足・サイトデータ消去・長期未使用でキャッシュが消えた場合、接続し直して復旧できる。
- [ ] 更新は全タブ／PWAを閉じた後に反映され、使用中のマイク画面が突然差し替わらない。

## プライバシーと継続使用

- [ ] ネットワークの監視でアプリ資産以外の自動通信、POST、WebSocket、音声・結果の送信がない。
- [ ] Cache Storageが固定アプリ資産だけで、音声・結果の永続保存がない。
- [ ] 開始後・停止後・ページ移動後に録音ファイルや結果履歴が作られない。
- [ ] 10〜15分使用して、画面応答・発熱・バッテリー低下・タブ再読み込みが許容範囲。
- [ ] 当日の端末・OS・マイク構成で、完全オフラインのリハーサルを実施。

SafariのリモートWeb Inspectorによる詳細監視には通常Macが必要です。WindowsのEdge/ChromeテストだけではiPad Safariの内部挙動を検証できません。Windows環境では実機の目視・機内モード確認を先に行い、詳細監視が必要な項目はMacなど検証可能な環境を用意するまで未確認のままにします。[WebKitの検査ガイド](https://webkit.org/web-inspector/enabling-web-inspector/)

## 将来モデルを導入するとき

- [ ] 用途・ライセンス確認、採用版LICENSEと帰属表示、変更履歴。
- [ ] 正規化と16 kHz化、ONNXの入出力、参照値との一致。
- [ ] 読み込み失敗やメモリ不足時に明確な状態を表示し、ダミースコアなし。
- [ ] 実測の読み込み時間・推論時間・メモリとオフラインキャッシュを検証。
- [ ] 停止／画面非表示で推論Worker・音声窓も解放。
